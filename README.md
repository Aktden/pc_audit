# Инженерный аудит и проектирование ПК

Практическая работа по дисциплине «Инструментальные средства разработки программного обеспечения», 3 курс.

## Состав репозитория

- `report.pdf` - отчёт с таблицами № 1–5, аналитикой, графиками и схемой.
- `estimate.xlsx` - редактируемая смета и таблицы № 1–5 на отдельных листах.
- `monitor.py` - сбор 30 точек CPU/RAM в двух режимах, CSV, JSON, графики и сводная статистика.
- `finalize.py` - пересборка PDF и Excel после локальных измерений и добавления скриншотов.
- `architecture.drawio` - редактируемая схема diagrams.net.
- `architecture.png` - изображение архитектуры для отчёта.
- `builds.json` - состав и цены вариантов А/Б.
- `sources.md` - ссылки на магазины и документацию производителей.
- `data/` - фактический паспорт компьютера, два CSV и сводная статистика.
- `evidence/` - место для собственных скриншотов системных утилит и конфигуратора.

## Фактически обследованный компьютер

Инвентаризация выполнена на **ZET Gaming WARD H195**:

| Компонент | Обнаруженные данные |
|---|---|
| CPU | Intel Core i5-11400F, 6 ядер / 12 потоков, L3 12 МБ |
| Материнская плата | MSI MAG B560M BAZOOKA, версия 2.0 |
| RAM | 16 ГиБ (2×8 ГБ) Patriot DDR4-3200 |
| GPU | NVIDIA GeForce RTX 3060, 12 ГБ VRAM по `nvidia-smi` |
| SSD | Samsung SSD 870 EVO 500GB, SATA |
| BIOS | AMI A.Z1; дата из WMI - 05.07.2021 |
| ОС | Windows NT 10.0, сборка 26300, AMD64 |

**Примечание по VRAM:** `Win32_VideoController` сообщил 4 ГБ, а `nvidia-smi` - 12 ГБ. Для RTX 3060 в отчёте принято значение `nvidia-smi` - 12 ГБ. Видеокарта RTX 3060 выпускалась в варианте с 12 ГБ GDDR6; сведения NVIDIA приведены в `sources.md`.

Модель БП и точная модель кулера не определяются обычным программным опросом. Их можно внести в `data/manual_hardware.json`, если есть достоверные сведения. Не вскрывайте блок питания.

## Установка (Windows 10/11)

Откройте PowerShell в папке проекта:

```powershell
py -m pip install -r requirements.txt
```

## Инвентаризация

```powershell
py monitor.py --inventory-only
```

Результат записывается в `data/machine.json`.

## Два измерения

Простой:

```powershell
py monitor.py --mode idle --samples 30 --interval 1
```

Рабочая нагрузка - откройте IDE, браузер примерно с 10 вкладками и запустите локальную программу:

```powershell
py monitor.py --mode workload --samples 30 --interval 1
```

В репозитории уже сохранены фактические результаты двух запусков: по 30 точек на режим. Повторный запуск соответствующего режима перезапишет его CSV.

После второго измерения создаются:
- `data/idle.csv`;
- `data/workload.csv`;
- `data/summary.json`;
- `graphs/cpu_comparison.png`;
- `graphs/ram_comparison.png`.
